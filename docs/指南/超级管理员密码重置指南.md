# 超级管理员密码重置指南

> **适用场景**: 忘记超级管理员密码，需要重置密码
> **创建日期**: 2025-01-29
> **相关工具**: PasswordGeneratorTool

---

## 问题场景

当遇到以下情况时，可以使用本指南：
- ❌ 忘记超级管理员密码
- ❌ 密码过期无法登录
- ❌ 需要为其他管理员重置密码
- ❌ 需要临时测试账号

---

## 解决方案

### 方式1：使用密码生成工具（推荐）

#### 步骤 1：进入项目目录

```bash
cd zhuque-backend/zhuque-common
```

#### 步骤 2：运行密码生成工具

```bash
# 方式 A：命令行指定手机号（推荐）
mvn exec:java -Dexec.mainClass="wake.su.zhuque.common.security.util.PasswordGeneratorTool" \
  -Dexec.args="13800138001"

# 方式 B：交互式输入
mvn exec:java -Dexec.mainClass="wake.su.zhuque.common.security.util.PasswordGeneratorTool"
# 然后输入手机号
```

#### 步骤 3：复制输出内容

工具会输出以下内容：

```
========================================
       密码生成工具 - 朱雀广告平台
========================================

使用命令行参数手机号: 13800138001

----------------------------------------
【明文密码】
  2026012913800138001

【哈希值】
  $2a$10$L8QI0BNFQsGzTWjvhJPRUezix7kDmJm8io6K7Ee7M.G9jdEYGv7cu

----------------------------------------
【SQL 更新语句】
-- 方式1：根据手机号更新（推荐）
UPDATE sys_user SET password = '$2a$10$...' WHERE phone = '13800138001';

-- 方式式2：根据用户ID更新
UPDATE sys_user SET password = '$2a$10$...' WHERE id = 1;

========================================
【密码验证】
  明文密码: 2026012913800138001
  哈希值:   $2a$10$...
  验证结果: ✅ 匹配
========================================
```

#### 步骤 4：连接数据库并执行 SQL

使用数据库客户端（如 Navicat、DBeaver、命令行等）连接到数据库，执行上面输出的 SQL 语句：

```sql
-- 根据手机号更新（推荐）
UPDATE sys_user
SET password = '$2a$10$L8QI0BNFQsGzTWjvhJPRUezix7kDmJm8io6K7Ee7M.G9jdEYGv7cu'
WHERE phone = '13800138001';
```

#### 步骤 5：使用新密码登录

- **用户名**: 输入手机号（如 `13800138001`）或用户名
- **密码**: 输入明文密码（如 `2026012913800138001`）

---

### 方式2：直接修改数据库（高级用户）

如果你熟悉数据库操作，也可以直接执行以下步骤：

#### 步骤 1：查询用户信息

```sql
-- 查看用户信息
SELECT id, username, phone, password
FROM sys_user
WHERE phone = '13800138001';
```

#### 步骤 2：获取今日日期

```sql
-- 查看当前日期
SELECT NOW() AS current_time;
```

假设今天是 2025-01-29，那么：
- **明文密码** = `20250129` + `13800138001` = `2025012913800138001`

#### 步骤 3：生成 BCrypt 哈希（使用工具）

```bash
# 调用工具生成哈希
mvn exec:java -Dexec.mainClass="wake.su.zhuque.common.security.util.PasswordGeneratorTool" \
  -Dexec.args="13800138001"
```

#### 步骤 4：更新密码

```sql
UPDATE sys_user
SET password = '$2a$10$...'  -- 替换为工具生成的哈希值
WHERE phone = '13800138001';
```

## 密码规则说明

### 明文密码格式

```
明文密码 = yyyyMMdd + 手机号
```

**示例**：
- 日期：2025-01-29
- 手机号：13800138001
- 明文密码：`2025012913800138001`

### 重要提示

⚠️ **密码每日变化**

由于密码包含当前日期（`yyyyMMdd`），所以：
- 每天的密码都不同
- 今天（2025-01-29）的密码是：`2025012913800138001`
- 明天（2025-01-30）的密码是：`2025013013800138001`

✅ **建议**：
- 定期更换密码
- 记录当天的日期，方便生成密码
- 可以设置日历提醒，定期重置密码

## 常见问题

### Q1：工具运行失败，提示找不到类

**原因**: Maven 依赖未下载或编译未完成

**解决方法**：
```bash
# 先编译项目
cd zhuque-backend/zhuque-common
mvn clean compile

# 再运行工具
mvn exec:java -Dexec.mainClass="wake.su.zhuque.common.security.util.PasswordGeneratorTool" \
  -Dexec.args="13800138001"
```

### Q2：SQL 执行后仍无法登录

**排查步骤**：

1. **确认用户名**：
```sql
SELECT username, phone FROM sys_user WHERE phone = '13800138001';
```
   - 如果 `username` 和 `phone` 不一致，使用正确的字段登录

2. **确认密码更新成功**：
```sql
SELECT password FROM sys_user WHERE phone = '13800138001';
```
   - 确认密码哈希值已更新

3. **检查用户状态**：
```sql
SELECT status, deleted FROM sys_user WHERE phone = '13800138001';
```
   - `status` 应为启用状态（通常 `status = 1`）
   - `deleted` 应为 `0`（未删除）

4. **检查是否有多条记录**：
```sql
SELECT COUNT(*) FROM sys_user WHERE phone = '13800138001';
```
   - 如果有多条，可能需要删除重复记录

### Q3：手机号不记得怎么办

**解决方案**：

1. **查看数据库中的手机号**：
```sql
-- 查看超级管理员
SELECT id, username, phone FROM sys_user
WHERE id = 1  -- 通常 ID=1 是超级管理员
  OR username = 'admin';
```

2. **使用用户ID更新密码**：
```bash
# 使用用户ID生成密码
# 注意：工具仍然需要手机号参数，但你可以手动修改 SQL 中的 WHERE 条件
mvn exec:java -Dexec.mainClass="wake.su.zhuque.common.security.util.PasswordGeneratorTool" \
  -Dexec.args="13800138001"
```

然后使用工具输出的第二个 SQL 语句：
```sql
-- 将下面的 1 替换为实际的用户ID
UPDATE sys_user SET password = '$2a$10$...' WHERE id = 1;
```

### Q4：忘记当前日期怎么办

工具会自动使用当前日期生成密码，无需手动计算。

**日期格式**: `yyyyMMdd`
- 2025年1月29日 → `20250129`
- 2025年12月31日 → `20251231`

## 安全建议

### 1. 密码重置后

- ✅ 登录后立即修改密码（如果系统支持）
- ✅ 检查是否有未授权的操作记录
- ✅ 通知相关人员密码已重置

### 2. 长期安全

- 🔄 定期更换密码（建议每月一次）
- 🔒 使用强密码策略（如果系统支持）
- 📝 记录密码重置历史
- 🚫 不要在多个系统使用相同密码

### 3. 权限管理

- ⭐ 超级管理员权限很大，谨慎使用
- 👥 日常操作使用普通管理员账号
- 📋 定期审计管理员列表
