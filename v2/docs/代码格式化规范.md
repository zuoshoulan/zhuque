# 代码格式化规范

本文档说明项目使用的代码格式化工具和规范，确保团队代码风格统一。

## 概述

| 语言 | 格式化工具 | 规范 |
|------|-----------|------|
| Java | Spotless + Google Java Format | 2空格缩进 |
| Rust | rustfmt | 4空格缩进（Rust 默认） |
| TypeScript/JavaScript | Prettier | 2空格缩进 |

## Java 格式化（Spotless + Google Java Style）

### 配置位置

`zhuque-backend/bid-java/pom.xml` 中已配置 Spotless 插件。

### 使用方法

```bash
# 进入 bid-java 目录
cd zhuque-backend/bid-java

# 检查代码格式（不修改文件）
mvn spotless:check

# 自动格式化代码
mvn spotless:apply
```

### Google Java Style 特点

- **缩进**：2空格
- **大括号**：K&R 风格（左大括号不换行）
- **行宽**：建议不超过 100 字符
- **导入顺序**：java/javax → org → com → 项目内部

### VSCode 集成

项目已配置好 VSCode 自动格式化，只需安装推荐的插件：

1. 安装推荐插件：`emeraldwalk.runonsave`（保存时自动运行 Spotless）
2. 打开任意 Java 文件，保存时自动执行 `mvn spotless:apply`

**手动格式化（Shift+Alt+F 替代方案）：**

使用 VSCode Tasks：
- `Ctrl+Shift+P` → 输入 `Tasks: Run Task` → 选择 `Spotless: Format Java`

或者绑定快捷键，在 `.vscode/keybindings.json` 中添加：

```json
[
  {
    "key": "shift+alt+f",
    "command": "workbench.action.tasks.runTask",
    "args": "Spotless: Format Java",
    "when": "editorLangId == java"
  }
]
```

### IntelliJ IDEA 集成

1. 安装插件：`Spotless`（搜索并安装）
2. 或在终端运行：`mvn spotless:apply`

### CI/CD 集成

Spotless 已配置在 `validate` 阶段自动检查格式：

```xml
<execution>
  <id>spotless-check</id>
  <phase>validate</phase>
  <goals>
    <goal>check</goal>
  </goals>
</execution>
```

格式不符时构建会失败，需运行 `mvn spotless:apply` 修复。

## Rust 格式化（rustfmt）

### 使用方法

```bash
# 检查格式（不修改文件）
cargo fmt --check

# 自动格式化代码
cargo fmt
```

### 配置文件

在 `Cargo.toml` 同级目录创建 `.rustfmt.toml`：

```toml
max_width = 100
hard_tabs = false
tab_spaces = 4
```

## 前端格式化（Prettier）

### 安装

```bash
npm install --save-dev prettier
```

### 配置文件

创建 `.prettierrc`：

```json
{
  "printWidth": 100,
  "tabWidth": 2,
  "trailingComma": "es5",
  "semi": true,
  "singleQuote": true
}
```

### 使用方法

```bash
# 检查格式
npx prettier --check .

# 自动格式化
npx prettier --write .
```

## 为什么选择 Spotless？

1. **跨 IDE 统一**：不管用 VSCode、IntelliJ 还是 Eclipse，格式化结果一致
2. **CI/CD 集成**：可以在流水线中强制检查
3. **支持多语言**：Java、Kotlin、Python、JavaScript、Rust 等
4. **团队协作**：减少代码审查时的格式争议

## 常见问题

### Q: VSCode 格式化后和 Spotless 不一致怎么办？

A: 禁用 VSCode 的 Java 格式化功能，改用 `mvn spotless:apply`。

### Q: 提交代码时格式检查失败？

A: 运行 `mvn spotless:apply` 后重新提交。

### Q: 想跳过格式检查怎么办？

A: 临时跳过：`mvn install -Dspotless.skip`（不推荐，仅紧急情况使用）
