# 投放管理界面设计文档

> **版本**: v1.0
> **日期**: 2025-01-24
> **架构**: 三层架构（Campaign → AdGroup → Ad）

---

## 一、页面层级结构

```
投放管理
├── 投放活动列表 (/campaigns)
├── 投放活动详情 (/campaigns/:id)
│   ├── 基本信息
│   ├── 广告组列表 (/campaigns/:id/ad-groups)
│   └── 数据报表
├── 广告组详情 (/ad-groups/:id)
│   ├── 基本信息
│   ├── 定向设置
│   ├── 出价设置
│   └── 广告列表 (/ad-groups/:id/ads)
└── 广告详情 (/ads/:id)
    ├── 基本信息
    └── 创意预览
```

### 2.2 列表字段说明

| 字段 | 说明 | 交互 |
|------|------|------|
| **活动名称** | Campaign.name | 点击进入详情页 |
| **营销目标** | campaign_objective | 显示为标签：品牌曝光/流量/转化/ROI |
| **总预算** | lifetime_budget | 显示为 "100万元"，鼠标悬浮显示精确数字 |
| **已消耗** | lifetime_budget_used | 进度条 + 百分比 "(45%)" |
| **状态** | status | ● 进行中(绿) / ⚪ 暂停(灰) / ⚫ 已完成(灰) |
| **时间** | start_time ~ end_time | 显示 "11.11-11.15" |

### 2.3 操作按钮

每行操作：
- **编辑**：修改基本信息、预算、时间
- **暂停/启动**：快速切换状态
- **复制**：快速创建相似活动
- **删除**：仅草稿状态可删除

### 10.9 表单验证规则汇总

**投放活动表单**：
```javascript
{
  // 基本信息
  campaign_name: {
    required: true,
    minLength: 2,
    maxLength: 100,
    pattern: /^[\u4e00-\u9fa5a-zA-Z0-9_\s-]+$/,
    message: "请输入2-100个字符，仅支持中英文、数字、下划线、空格和连字符"
  },

  campaign_description: {
    required: false,
    maxLength: 500,
    message: "描述不能超过500个字符"
  },

  // 营销目标
  campaign_objective: {
    required: true,
    enum: [1, 2, 3, 4], // 1=品牌曝光 2=流量 3=转化 4=ROI
    message: "请选择营销目标"
  },

  campaign_goal_type: {
    required: false,
    enum: [1, 2, 3], // 1=展示 2=点击 3=转化
    dependsOn: 'campaign_objective',
    message: "请选择目标类型"
  },

  campaign_goal_value: {
    required: false,
    type: 'number',
    min: 1000,
    max: 1000000000,
    message: "目标值范围为1,000 - 1,000,000,000"
  },

  // 预算设置
  lifetime_budget: {
    required: true,
    type: 'decimal',
    min: 100,
    max: 100000000,
    precision: 2,
    message: "预算不能少于100元，不超过1亿元"
  },

  // 时间设置
  start_time: {
    required: true,
    type: 'datetime',
    min: new Date(), // 不能早于当前时间
    message: "开始时间不能早于当前时间"
  },

  end_time: {
    required: true,
    type: 'datetime',
    min: function() { return this.start_time + 3600000 }, // 至少1小时后
    max: function() { return this.start_time + 7776000000 }, // 最多90天后
    custom: function(value) {
      const days = (value - this.start_time) / 86400000;
      return days <= 90;
    },
    message: "活动时长必须在1小时-90天之间"
  }
}
```

**广告组表单**：
```javascript
{
  // 基本信息
  ad_group_name: {
```

### 10.10 错误处理与用户反馈

**错误等级定义**：
```
等级1：提示信息（蓝色ℹ️）
  - 用于：操作成功提示、信息告知
  - 交互：3秒后自动消失，可手动关闭
  - 示例："✅ 已保存成功！"

等级2：警告提示（黄色⚠️）
  - 用于：潜在风险、智能建议
  - 交互：5秒后自动消失，可手动关闭
  - 示例："⚠️ 出价过低可能导致竞争力不足"

等级3：错误提示（红色❌）
  - 用于：操作失败、验证错误
  - 交互：不自动消失，需手动关闭
  - 示例："❌ 保存失败，请重试"

等级4：致命错误（红色✗）
  - 用于：系统错误、网络中断
  - 交互：全屏遮罩，强制用户处理
  - 示例："✗ 系统异常，请刷新页面或联系客服"
```

**错误提示显示规则**：
```javascript
// Toast提示配置
{

  scroll_to_first: true     // 滚动到第一个错误字段
}
```

**常见错误场景处理**：
```
场景1：网络请求超时（>10秒）
  前端处理：
    ├─ 取消请求
    ├─ 显示错误提示："⏱️ 请求超时，请检查网络连接"
    ├─ 提供 [ 重试 ] 按钮
    └─ 如果3次重试都失败，提示："请联系客服"

场景2：服务器错误（500）
  前端处理：
    ├─ 显示错误提示："❌ 服务器内部错误"
    ├─ 提供 [ 刷新页面 ] 按钮
    ├─ 自动上报错误日志（包含请求详情）
    └─ 显示错误编号（方便客服排查）

场景3：权限不足（403）
  前端处理：
    ├─ 显示错误提示："🔒 您没有权限执行此操作"
    ├─ 如果是登录过期，跳转登录页
    └─ 如果是权限不足，提供 [ 联系管理员 ] 按钮

场景4：数据冲突（409）
  前端处理：
    ├─ 显示错误提示："⚠️ 数据冲突"
    ├─ 提示冲突原因："该名称已被使用"
    ├─ 提供 [ 自动重命名 ] 选项
    │   └─ "双11大促" → "双11大促 (2)"
    └─ 提供 [ 强制保存 ] 选项（需要更高权限）

场景5：表单验证失败（400）
  前端处理：
    ├─ 解析错误字段列表
    ├─ 高亮第一个错误字段
    ├─ 在每个字段下方显示具体错误
    ├─ 滚动到第一个错误字段
    └─ 禁用提交按钮直到所有错误修复
```
