## 🎯 项目总览

### 重写目标
- **技术栈升级**: Spring Boot 2.1 → 3.2.x, Vue 2 → Vue 3 + TypeScript
- **架构改进**: 单体应用 + 模块化分层，清晰的接口驱动设计
- **功能完善**: 实现RTB竞价、监测服务等核心功能
- **质量提升**: 完善测试、文档和监控体系

### 技术选型
- **后端**: Spring Boot 3.2.x + JDK 17/21 + MyBatis-Plus + MySQL 8.0 + Redis 7.x
- **前端**: Vue 3.4.x + TypeScript 5.x + Vite 5.x + Element Plus
- **安全**: Spring Security + JWT
- **监控**: Micrometer + Prometheus + ELK
- **架构**: 单体应用（Maven多模块）+ 接口驱动

## 🔍 技术难点提示

### 高优先级技术难点
1. **RTB协议对接**
   - OpenRTB协议标准复杂
   - 建议参考IAB官方文档
   - 可先实现简化版本

2. **竞价决策引擎**
   - 需要高性能算法
   - 考虑使用Redis做缓存
   - 可引入规则引擎

3. **高并发处理**
   - 监测服务QPS可能很高
   - 考虑使用异步处理（Kafka）
   - 实现读写分离

4. **数据一致性**
   - 预算扣减需要精确
   - 考虑使用分布式事务
   - 实现最终一致性
